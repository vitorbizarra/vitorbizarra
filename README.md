# Olá, eu sou Vitor Bizarra! 👋

### Desenvolvedor Full Stack | PHP • Laravel • TALL Stack

Sou desenvolvedor de software com foco em **PHP e Laravel**, atuando no desenvolvimento e manutenção de aplicações web, APIs, integrações com serviços externos e sistemas legados.

Atualmente, também trabalho com a integração de **Inteligência Artificial** em aplicações Laravel, utilizando tecnologias como **RAG, bancos vetoriais e Docker** para construção de assistentes especializados e recuperação semântica de informações.

## 👨‍💻 Sobre mim

* 🎓 Tecnólogo em **Análise e Desenvolvimento de Sistemas** pela Facens.
* 🐘 Foco profissional em **PHP e Laravel**.
* ⚡ Experiência com **TALL Stack** — Tailwind CSS, Alpine.js, Laravel e Livewire.
* 🔌 Desenvolvimento de **APIs REST e integrações com serviços externos**.
* 🤖 Integração de aplicações com **modelos de Inteligência Artificial, RAG e bancos vetoriais**.
* 🐳 Utilização de **Docker** para desenvolvimento e infraestrutura de aplicações.
* 🗄️ Experiência com bancos de dados relacionais, especialmente **MySQL**.
* 🚀 Interesse constante em arquitetura, qualidade de código, performance e boas práticas de desenvolvimento.
